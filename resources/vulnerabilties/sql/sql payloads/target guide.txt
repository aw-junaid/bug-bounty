 HOW TO USE
------------------------------------------------------------------------
 1. In Burp Suite: send request to Intruder
 2. Set attack type: Sniper (single param) or Pitchfork (multi)
 3. Mark the parameter value as §payload§
 4. Payload Sets → Load from file → pick the relevant .txt below
 5. For time-based: set Resource Pool → max 1 concurrent request
    Filter results by response time > 4500ms = potential SQLi
 6. For boolean: compare response length/content between payloads

                         URL: /workspace-signin?redir=https://evil.com

  2. query param      → SQLi time-based blind

  3. filter param     → SQLi / XSS

  5. entry_point      → Second-order / XSS (reflected in page routing)
                         URL: /get-started?entry_point=§payload§

  6. from param       → Open redirect / Second-order

  7. slug / category  → SQLi via dynamic WHERE clause
