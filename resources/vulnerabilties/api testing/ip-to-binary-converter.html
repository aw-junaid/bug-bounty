✦ How This Tool Works

What real problem does this solve?

Subnetting, ACL wildcard masks, and understanding why a /26 splits a /24 into four blocks all come down to reading bits directly. This tool converts addresses to binary instantly, colors which bits are "network" vs. "host" for a given prefix, and lets you reverse the process — paste bits and get an address back — so you can check hand-worked subnetting problems in seconds instead of re-deriving them.

How does the Network / Host Bit Split work?

Given an address and a prefix (explicit /n, or the default prefix from settings), every bit up to the prefix length is shaded as "network" and every bit after it as "host." The first host bit is flagged separately since flipping it is what moves you into the next subnet — the trick behind the classic subnetting "magic number."

What's a wildcard mask, and why is it inverted?

Cisco IOS access-control lists match traffic using a wildcard mask rather than a subnet mask — a 0 bit means "must match," a 1 bit means "don't care." It's the bitwise complement of the netmask, so a /24's mask 255.255.255.0 becomes wildcard 0.0.0.255. The Wildcard Mask Generator produces both from a single CIDR input.

Can I paste binary and get an IP back?

Yes — switch to "Binary → IP" mode and paste four 8-bit groups (IPv4) or eight 16-bit hex/binary groups (IPv6), separated however you like. With "Ignore spaces/dots" on, formats like 11000000.10101000.00000001.00001010 or space-separated bits both parse correctly.

What does "common prefix length" tell me?

It's the number of leading bits two addresses share. That number is exactly the longest CIDR prefix of a single block that could contain both addresses — useful when summarizing routes or figuring out the smallest supernet spanning two subnets.

Is anything sent to a server?

No. Every conversion — binary, hex, decimal, bit-splitting, wildcard masks, the quiz — runs entirely in your browser with plain JavaScript. Your draft input and settings only persist in this browser's local storage, and nothing here makes a network request.
