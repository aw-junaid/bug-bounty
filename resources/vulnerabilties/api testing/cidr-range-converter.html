✦ How This Tool Works

What problem does this actually solve?

CIDR notation and start-end ranges are both common, but different systems demand different forms — cloud security groups want CIDR, some legacy ACLs and vulnerability scanners want ranges, and neither converts itself. This tool batch-converts both directions, collapses a messy list of rules into the minimal CIDR set that covers them, and turns the result straight into paste-ready firewall config.

What does "auto-merge" actually change?

When enabled, every valid line is combined into intervals first, overlapping or directly adjacent ranges are joined, and only then is the merged set converted to CIDR blocks. This is real-world supernetting — ten overlapping ACL entries might collapse into two or three blocks, which is exactly what you want before deploying a rule set.

How does exclude / subtract work?

Enable exclude mode and enter a second list. Each excluded address or block is cut out of the main input's range using interval subtraction — so "allow 10.0.0.0/24 except 10.0.0.5 and 10.0.0.128/28" correctly produces the remaining fragments as their own CIDR blocks, not an invalid negative rule.

Why does overlap detection matter?

Overlapping firewall or ACL entries are a common source of confusing, hard-to-audit rule sets — a broad rule can silently swallow a more specific one placed after it. This checks every pair of input lines and reports which ones intersect, so you can catch redundant or conflicting entries before deployment.

Are the exported config snippets ready to use as-is?

They're a correct starting point using the CIDR blocks from your current result (merged and/or excluded, depending on your settings), but you should still set the correct chain, interface, zone, or security-group ID for your environment — this tool doesn't know your topology.

Is anything sent to a server?

No, with one exception: the "Detect My Public IP" button is opt-in and calls a third-party API (ipify.org) to look up your public IP. Everything else — parsing, merging, subtracting, overlap detection, and config generation — runs entirely in your browser. Your draft and settings only persist in this browser's local storage.
